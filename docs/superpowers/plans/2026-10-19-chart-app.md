# weaselchart, first arc — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `apps/chart` — a Visio-style editor with a chart mode (scene is the document) and a pipeline mode (an `EffectPipeline` is the document) — with every editing ability built as engine surface in `@weasel-js/diagram`.

**Architecture:** Each editing ability is a scene action with a swappable `commit`: the default writes scene ops; `DiagramView` swaps in callbacks that report data edits. Pipeline editing is a pure edit model plus an `EffectEditor` view in `diagram/effect`, on the `nodeGraph` look only. Glue shared with draw moves into `apps/shared/editor/`, aliased `@editor/*`.

**Tech Stack:** TypeScript, React 18, vite, vitest (jsdom `vmThreads` + browser project), `@weasel-js/core`, `@weasel-js/diagram`, `@weasel-js/ui`, `@weasel-js/history`.

**Spec:** `docs/superpowers/specs/2026-10-19-chart-app-design.md`

## Global Constraints

- Every test, typecheck, lint and build runs on the fleet, never locally — not even one file. Scoped run: commit, then `onto do --kind test -- npx vitest run --project=<p> <files>` (`--kind typecheck -- npm run typecheck` for types). Branch-level: `npm run test:fleet` and `npm run test:gate`. Local work is limited to scripts that finish in a second or two (`npm run check:size`, generators).
- Core and diagram tests run under the root config: `--project=core` owns `packages/core` and `packages/diagram`; check with `npm run check:test-projects` output if unsure. App and `apps/shared` tests run under `--project=draw`. Browser tests are `*.browser.test.tsx` (`--project=browser`).
- Tools are declarative shells (bindings + `ToolDef.actions`); a tool hook never calls `useAction`. No tool runs its own gesture.
- Kit types stay generic over `TPose`; no `{x, y}` baked in without saying so.
- Apps import public package surface only. No `@internal`.
- `npm run check:size`: files ≤ 400 lines, functions ≤ 120.
- Changesets: `patch`, always. Breaking or additive changes are said in the changeset prose.
- Inside `apps/shared/editor/src`, imports between its own files are relative; it imports nothing from `apps/draw` or `apps/chart`.
- One pathway per decision: when a helper is extracted (label spec, edge id), every existing caller switches to it in the same task.
- Comments sparingly (see `CLAUDE.md`). US English.
- Commit subjects: imperative, repo vocabulary, end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **A connector dropped on empty canvas, or on its own source shape's body** — nothing commits, no stray edge node; tested in Task 2.
- **Reconnecting an end onto the edge's other end's shape** (self-loop) is allowed only through ports, never body-to-same-body; tested in Task 3.
- **Deleting a stage in pipeline mode that has wires in and out** removes those wires from `pipeline.wires` and its entry from `places`; tested in Task 7.
- **A wire between mismatched value types** never reaches `onChange` in `EffectEditor`; tested in Task 8.
- **Undo in chart mode after a reconnect** restores the original end and `dependsOn`; tested in Task 3.
