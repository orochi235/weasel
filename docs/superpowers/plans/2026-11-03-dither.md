# Dithering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@weasel-js/dither`: a CPU ditherer for exported pixels (four methods, with protected regions) and a GPU effect that shows threshold or Bayer dithering live on the canvas, on the screen grid or on an output target's dot grid.

**Architecture:** One new package depending on `@weasel-js/geom` and `@weasel-js/renderer`. The CPU path and the GPU shader share one definition of the Bayer matrix, the luminance weights, and the default threshold. The GPU path is an ordinary renderer `Effect`, which needs one renderer change (effect passes learn where their buffer sits in the drawing buffer) and one core typing change (a layer group's effect thunk sees `dpr`). Spec: `docs/superpowers/specs/2026-11-03-dither-design.md`.

**Tech Stack:** TypeScript, WebGL2 GLSL ES 3.00, vitest (`weasel-ui` project for jsdom tests, `browser` project for `*.browser.test.ts` in headless Chromium), tsup.

```ts
// packages/dither/src/shared.ts
/** The classic 4×4 Bayer index matrix, row-major. The GPU shader embeds this
 *  same array, so the two paths cannot drift. */
export const BAYER_4X4: readonly number[] = [0, 8, 2, 10, 12, 4, 14, 6, 3, 11, 1, 9, 15, 7, 13, 5];

/** Rec. 601 luma weights. */
export const LUMA: readonly [number, number, number] = [0.299, 0.587, 0.114];

export const DEFAULT_THRESHOLD = 128;

export const WHITE: readonly [number, number, number] = [255, 255, 255];

/** The gray an ordered dither compares against at dot (x, y): below it is ink. */
export function bayerCutoff(x: number, y: number, threshold: number): number {
  const m = BAYER_4X4[(((y % 4) + 4) % 4) * 4 + (((x % 4) + 4) % 4)]!;
  return (m + 0.5) * 16 + (threshold - DEFAULT_THRESHOLD);
}
```

```ts
// packages/dither/src/gray.ts
import { LUMA, WHITE } from './shared';
import type { Rgb, RgbaImage } from './types';

/** Each pixel's gray, 0–255, after compositing it over `background`. */
export function toGray(image: RgbaImage, background: Rgb = WHITE): Float32Array {
  const n = image.width * image.height;
  const gray = new Float32Array(n);
  const d = image.data;
  for (let i = 0; i < n; i++) {
    const a = d[i * 4 + 3]! / 255;
    const r = d[i * 4]! * a + background[0] * (1 - a);
    const g = d[i * 4 + 1]! * a + background[1] * (1 - a);
    const b = d[i * 4 + 2]! * a + background[2] * (1 - a);
    gray[i] = LUMA[0] * r + LUMA[1] * g + LUMA[2] * b;
  }
  return gray;
}
```

```ts
// packages/dither/src/protectMask.ts
import type { Rect } from '@weasel-js/geom';

/** A per-pixel protect mask (1 = protected) from rects in pixel space. Rects
 *  round outward to whole pixels and clip to the image. */
export function protectMask(rects: Iterable<Rect>, width: number, height: number): Uint8Array {
  const mask = new Uint8Array(width * height);
  for (const r of rects) {
    const x0 = Math.max(0, Math.floor(r.x));
    const y0 = Math.max(0, Math.floor(r.y));
    const x1 = Math.min(width, Math.ceil(r.x + r.width));
    const y1 = Math.min(height, Math.ceil(r.y + r.height));
    for (let y = y0; y < y1; y++) mask.fill(1, y * width + x0, y * width + Math.max(x0, x1));
  }
  return mask;
}
```

```ts
// packages/dither/src/ditherPixels.ts
import { ATKINSON, FLOYD_STEINBERG, diffuse } from './diffuse';
import { toGray } from './gray';
import { DEFAULT_THRESHOLD, WHITE, bayerCutoff } from './shared';
import type { DitherOptions, RgbaImage } from './types';

/** `image` quantized to ink: one byte per pixel, 1 = ink. */
export function ditherPixels(image: RgbaImage, options: DitherOptions = {}): Uint8Array {
  const { method = 'threshold', threshold = DEFAULT_THRESHOLD, background = WHITE, protect } = options;
  const { width, height } = image;
  if (protect && protect.length !== width * height) {
    throw new RangeError(`ditherPixels: protect holds ${protect.length} pixels, the image ${width * height}`);
  }
  const gray = toGray(image, background);
  switch (method) {
    case 'threshold': {
      const mask = new Uint8Array(width * height);
      for (let i = 0; i < mask.length; i++) mask[i] = gray[i]! < threshold ? 1 : 0;
      return mask;
    }
    case 'bayer': {
      const mask = new Uint8Array(width * height);
      for (let y = 0; y < height; y++) {
        for (let x = 0; x < width; x++) {
          const i = y * width + x;
          const cutoff = protect?.[i] ? threshold : bayerCutoff(x, y, threshold);
          mask[i] = gray[i]! < cutoff ? 1 : 0;
        }
      }
      return mask;
    }
    case 'floyd-steinberg':
      return diffuse(gray, width, height, threshold, FLOYD_STEINBERG, 16, protect ?? null);
    case 'atkinson':
      return diffuse(gray, width, height, threshold, ATKINSON, 8, protect ?? null);
  }
}
```

```ts
// packages/dither/src/diffuse.ts
/** Where a pixel's quantization error goes: offset and weight numerator. */
export type Kernel = readonly (readonly [dx: number, dy: number, weight: number])[];

export const FLOYD_STEINBERG: Kernel = [[1, 0, 7], [-1, 1, 3], [0, 1, 5], [1, 1, 1]];

/** Spreads 6/8 of the error, which keeps highlights and shadows clean. */
export const ATKINSON: Kernel = [[1, 0, 1], [2, 0, 1], [-1, 1, 1], [0, 1, 1], [1, 1, 1], [0, 2, 1]];

/** Error diffusion over `gray`, which it consumes. A protected pixel quantizes
 *  at `threshold` against a value nothing diffused into, and sends no error. */
export function diffuse(
  gray: Float32Array,
  width: number,
  height: number,
  threshold: number,
  kernel: Kernel,
  denominator: number,
  protect: Uint8Array | null,
): Uint8Array {
  const mask = new Uint8Array(width * height);
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const i = y * width + x;
      const old = gray[i]!;
      const ink = old < threshold;
      mask[i] = ink ? 1 : 0;
      if (protect?.[i]) continue;
      const err = old - (ink ? 0 : 255);
      for (const [dx, dy, w] of kernel) {
        const nx = x + dx;
        const ny = y + dy;
        if (nx < 0 || nx >= width || ny >= height) continue;
        const ni = ny * width + nx;
        if (protect?.[ni]) continue;
        gray[ni] = gray[ni]! + (err * w) / denominator;
      }
    }
  }
  return mask;
}
```

```ts
import type { OutputGrid, Rect } from '@weasel-js/geom';

/**
 * Rects to protect, in dot space (one unit per dot, from the grid's origin),
 * the pixel space an export rendered at the grid's resolution has.
 * `protectedRect` answers an item's rect in document units, which may be
 * larger than the item (a barcode's quiet zone), or false or null to leave
 * it to the dither.
 */
export function protectRects<T>(
  items: Iterable<T>,
  protectedRect: (item: T) => Rect | false | null,
  grid: OutputGrid,
): Rect[] {
  const out: Rect[] = [];
  for (const item of items) {
    const r = protectedRect(item);
    if (!r) continue;
    out.push({
      x: (r.x - grid.origin.x) / grid.pitch,
      y: (r.y - grid.origin.y) / grid.pitch,
      width: r.width / grid.pitch,
      height: r.height / grid.pitch,
    });
  }
  return out;
}
```

```ts
// packages/dither/src/gpu/gridOnScreen.ts
import type { OutputGrid, View } from '@weasel-js/geom';

/** A dot grid in device pixels of the drawing buffer, from its top left. */
export interface DeviceGrid {
  pitch: readonly [number, number];
  origin: readonly [number, number];
}

/** `grid` where `view` at `dpr` puts it. In a layer group's effect thunk,
 *  `dpr` is `dims.dpr`; in a node's draw, `ctx.pixelScale / view.scale.x`. */
export function gridOnScreen(grid: OutputGrid, view: View, dpr: number): DeviceGrid {
  const sx = view.scale.x * dpr;
  const sy = view.scale.y * dpr;
  return {
    pitch: [grid.pitch * sx, grid.pitch * sy],
    origin: [(grid.origin.x - view.x) * sx, (grid.origin.y - view.y) * sy],
  };
}
```

```ts
// packages/dither/src/gpu/frag.ts
import { BAYER_4X4, LUMA } from '../shared';

const list = (xs: readonly number[]) => xs.map((x) => x.toFixed(4)).join(', ');

/**
 * One fragment per device pixel. On an output grid, a dot wider than a pixel
 * takes the mean of its footprint on at most 4×4 taps and quantizes once, so
 * every pixel of the dot agrees; a dot narrower than a pixel cannot be shown,
 * and the pixel quantizes alone, on the Bayer cell of its own device pixel.
 */
export const DITHER_FRAG = /* glsl */ `#version 300 es
precision highp float;
in vec2 v_uv;
uniform sampler2D u_source;
uniform vec2 u_resolution;
uniform vec2 u_windowOrigin;
uniform float u_method;      // 0 threshold, 1 bayer
uniform float u_threshold;   // 0-255
uniform vec3 u_background;   // 0-1
uniform vec4 u_ink;          // premultiplied 0-1
uniform vec4 u_blank;        // premultiplied 0-1
uniform vec2 u_pitch;        // device px per dot
uniform vec2 u_gridOrigin;   // device px, top-down
uniform sampler2D u_protect; // one texel per dot, red > 0.5 = protected
uniform vec2 u_protectSize;  // dots; 0 = none
out vec4 outColor;

const float BAYER[16] = float[16](${list(BAYER_4X4)});
const vec3 LUMA = vec3(${list(LUMA)});

float grayOf(vec4 p) {
  return dot(p.rgb + u_background * (1.0 - p.a), LUMA) * 255.0;
}

vec2 uvOf(vec2 devicePx) {
  vec2 local = (devicePx - u_windowOrigin) / u_resolution;
  return vec2(local.x, 1.0 - local.y);
}

void main() {
  vec2 px = u_windowOrigin + vec2(v_uv.x, 1.0 - v_uv.y) * u_resolution;
  vec2 dotIndex = floor((px - u_gridOrigin) / u_pitch);
  bool fine = u_pitch.x < 1.0 || u_pitch.y < 1.0;

  float gray;
  if (fine) {
    gray = grayOf(texture(u_source, v_uv));
  } else {
    vec2 start = u_gridOrigin + dotIndex * u_pitch;
    vec2 taps = clamp(ceil(u_pitch), vec2(1.0), vec2(4.0));
    vec4 sum = vec4(0.0);
    float n = 0.0;
    for (int j = 0; j < 4; j++) {
      if (float(j) >= taps.y) break;
      for (int i = 0; i < 4; i++) {
        if (float(i) >= taps.x) break;
        vec2 uv = uvOf(start + (vec2(float(i), float(j)) + 0.5) * u_pitch / taps);
        if (any(lessThan(uv, vec2(0.0))) || any(greaterThan(uv, vec2(1.0)))) continue;
        sum += texture(u_source, uv);
        n += 1.0;
      }
    }
    gray = grayOf(n > 0.0 ? sum / n : texture(u_source, v_uv));
  }

  bool protectedDot = u_protectSize.x > 0.0
    && all(greaterThanEqual(dotIndex, vec2(0.0))) && all(lessThan(dotIndex, u_protectSize))
    && texelFetch(u_protect, ivec2(dotIndex), 0).r > 0.5;

  float cutoff = u_threshold;
  if (u_method > 0.5 && !protectedDot) {
    vec2 cell = mod(fine ? floor(px) : dotIndex, 4.0);
    cutoff = (BAYER[int(cell.y) * 4 + int(cell.x)] + 0.5) * 16.0 + (u_threshold - 128.0);
  }
  outColor = gray < cutoff ? u_ink : u_blank;
}
`;
```

```ts
  /** Default `'threshold'`. Error diffusion runs on the CPU only. */
  method?: 'threshold' | 'bayer';
  /** Gray (0–255) below it is ink. Default 128. */
  threshold?: number;
  /** What transparency composites over before gray is taken. Default white. */
  background?: Rgb;
  /** Default opaque black. */
  ink?: Rgba;
  /** Default transparent. */
  blank?: Rgba;
  /** `'screen'` (one dot per device pixel, the default), or an output grid
   *  placed with `gridOnScreen`. */
  grid?: 'screen' | DeviceGrid;
  /** A protect mask in dot space, from `protectTexture`. Needs an output grid. */
  protect?: { texture: TextureHandle; width: number; height: number };
}

const premultiplied = ([r, g, b, a]: Rgba): number[] => {
  const k = a / 255;
  return [(r / 255) * k, (g / 255) * k, (b / 255) * k, k];
};

/** Threshold or Bayer dithering as one effect pass. */
export function dither(options: GpuDitherOptions = {}): Effect[] {
  const method = options.method ?? 'threshold';
  if (method !== 'threshold' && method !== 'bayer') {
    throw new Error(`dither: '${String(method)}' is error diffusion, which runs on the CPU only (ditherPixels)`);
  }
  const grid = options.grid === undefined || options.grid === 'screen' ? SCREEN : options.grid;
  const background = options.background ?? WHITE;
  const reach = grid === SCREEN ? 0 : Math.ceil(Math.max(grid.pitch[0], grid.pitch[1]));
  return [{
    program: PROGRAM,
    reach,
    uniforms: {
      u_method: method === 'bayer' ? 1 : 0,
      u_threshold: options.threshold ?? DEFAULT_THRESHOLD,
      u_background: [background[0] / 255, background[1] / 255, background[2] / 255],
      u_ink: premultiplied(options.ink ?? INK),
      u_blank: premultiplied(options.blank ?? BLANK),
      u_pitch: [grid.pitch[0], grid.pitch[1]],
      u_gridOrigin: [grid.origin[0], grid.origin[1]],
      ...(options.protect
        ? { u_protect: options.protect.texture, u_protectSize: [options.protect.width, options.protect.height] }
        : { u_protectSize: [0, 0] }),
    },
  }];
}
```

```ts
// packages/dither/src/gpu/protectTexture.ts
import { registerTexture, unregisterTexture, type TextureHandle } from '@weasel-js/renderer';

export interface ProtectTexture {
  texture: TextureHandle;
  width: number;
  height: number;
  /** Unregister the texture and free its bitmap. */
  dispose(): void;
}

/** A protect mask (from `protectMask`, in dot space) as a texture `dither`
 *  can read. The caller disposes it when the mask changes or the view goes. */
export async function protectTexture(mask: Uint8Array, width: number, height: number): Promise<ProtectTexture> {
  const data = new Uint8ClampedArray(width * height * 4);
  for (let i = 0; i < width * height; i++) {
    const v = mask[i] ? 255 : 0;
    data[i * 4] = v;
    data[i * 4 + 1] = v;
    data[i * 4 + 2] = v;
    data[i * 4 + 3] = 255;
  }
  const bitmap = await createImageBitmap(new ImageData(data, width, height));
  const texture = registerTexture(bitmap);
  return {
    texture, width, height,
    dispose() {
      unregisterTexture(texture);
      bitmap.close();
    },
  };
}
```

```ts
/**
 * The dither effect against the CPU ditherer, pixel for pixel, in real WebGL2.
 */
import { afterEach, describe, expect, it } from 'vitest';
import { WeaselRenderer, type DrawCommand } from '@weasel-js/renderer';
import { ditherPixels } from '../ditherPixels';
import { protectMask } from '../protectMask';
import { dither } from './dither';
import { protectTexture, type ProtectTexture } from './protectTexture';

const SIZE = 64;
const ORIGIN = 8;
const DOTS = 12;
// Each at least 4 from every Bayer cutoff ((m + 0.5) * 16) and from 128, so
// float rounding on the GPU cannot flip a dot.
const GRAYS = [60, 100, 140, 210];

const hex = (g: number) => `#${g.toString(16).padStart(2, '0').repeat(3)}`;
const grayOfDot = (x: number) => GRAYS[Math.floor(x / 3)]!;

/** Bands three dots wide, in device pixels at `k` pixels per dot. */
function bands(k: number): DrawCommand[] {
  return GRAYS.map((g, b) => ({
    kind: 'path',
    path: { kind: 'rect', x: ORIGIN + b * 3 * k, y: ORIGIN, width: 3 * k, height: DOTS * k },
    fill: { paint: { color: hex(g) } },
  }));
}

/** The same bands at one pixel per dot, as the CPU path sees an export. */
function dotImage() {
  const data = new Uint8ClampedArray(DOTS * DOTS * 4);
  for (let y = 0; y < DOTS; y++) {
    for (let x = 0; x < DOTS; x++) {
      const i = (y * DOTS + x) * 4;
      data.fill(grayOfDot(x), i, i + 3);
      data[i + 3] = 255;
    }
  }
  return { width: DOTS, height: DOTS, data };
}

let renderer: WeaselRenderer | undefined;
let held: ProtectTexture | undefined;
afterEach(() => {
  renderer?.dispose();
  renderer = undefined;
  held?.dispose();
  held = undefined;
});

/** Each dot's ink as the GPU drew it, read from the dot's top-left pixel. */
function render(commands: DrawCommand[], k: number): number[] {
  const canvas = document.createElement('canvas');
  canvas.width = SIZE;
  canvas.height = SIZE;
  const gl = canvas.getContext('webgl2', { stencil: true })!;
  renderer = new WeaselRenderer({ gl, width: SIZE, height: SIZE, dpr: 1 });
  renderer.render(commands);
  const px = new Uint8Array(SIZE * SIZE * 4);
  gl.readPixels(0, 0, SIZE, SIZE, gl.RGBA, gl.UNSIGNED_BYTE, px);
  const ink: number[] = [];
  for (let y = 0; y < DOTS; y++) {
    for (let x = 0; x < DOTS; x++) {
      // Every pixel of a dot must agree; check them all, report the dot.
      const values = new Set<number>();
      for (let dy = 0; dy < k; dy++) {
        for (let dx = 0; dx < k; dx++) {
          const row = SIZE - 1 - (ORIGIN + y * k + dy);
          values.add(px[(row * SIZE + ORIGIN + x * k + dx) * 4]! < 128 ? 1 : 0);
        }
      }
      expect(values.size, `dot (${x}, ${y}) at ${k} px per dot`).toBe(1);
      ink.push([...values][0]!);
    }
  }
  return ink;
}

const options = (k: number) => ({
  ink: [0, 0, 0, 255] as const,
  blank: [255, 255, 255, 255] as const,
  grid: { pitch: [k, k] as const, origin: [ORIGIN, ORIGIN] as const },
});

describe('dither effect against ditherPixels', () => {
  for (const method of ['threshold', 'bayer'] as const) {
    for (const k of [1, 2, 3, 4]) {
      it(`${method}, ${k} device px per dot`, () => {
        const gpu = render([{ kind: 'group', effects: dither({ method, ...options(k) }), children: bands(k) }], k);
        expect(gpu).toEqual(Array.from(ditherPixels(dotImage(), { method })));
      });
    }
  }

  it('bayer with the right half protected', async () => {
    const mask = protectMask([{ x: 6, y: 0, width: 6, height: DOTS }], DOTS, DOTS);
    held = await protectTexture(mask, DOTS, DOTS);
    const k = 2;
    const effects = dither({ method: 'bayer', ...options(k), protect: held });
    const gpu = render([{ kind: 'group', effects, children: bands(k) }], k);
    expect(gpu).toEqual(Array.from(ditherPixels(dotImage(), { method: 'bayer', protect: mask })));
  });
});
```

````markdown
# @weasel-js/dither

Turns pixels into 1-bit ink: on the CPU for the pixels an export produces,
and as a renderer effect that shows the dither live on the canvas.

Part of [weasel](https://github.com/orochi235/weasel), a domain-agnostic 2D
scene-graph canvas kit for React. See the
[API reference](https://orochi235.github.io/weasel/#pkg/dither).

```sh
npm install @weasel-js/dither
```

## Export

`ditherPixels(image, { method, threshold, background, protect })` takes
straight RGBA (what `renderSceneToPixels` returns) and answers one byte per
pixel, 1 for ink. `method` is `'threshold'`, `'bayer'`, `'floyd-steinberg'`
or `'atkinson'`. `maskToRgba` paints the result in two colors.

## Live

`dither({ method, grid, ink, blank })` is an `Effect[]` for a group or layer
group: threshold or Bayer, since error diffusion cannot run in a shader. On
the screen grid each device pixel is a dot. On an output grid, a printer's or
a 1-bit panel's, each dot is one dot of the target, so the canvas shows what
the export will print at any zoom:

```ts
const grid = { pitch: 72 / 180, origin: { x: 0, y: 0 } }; // 180 dpi, in points
const layerGroup = {
  id: 'print',
  layers: ['scene'],
  effects: (view, dims) => dither({ method: 'bayer', grid: gridOnScreen(grid, view, dims.dpr) }),
};
```

## Keeping things out of the dither

Put the dither on the groups that have tone (a photo) and end the page with a
`threshold` pass, and a barcode or a line of type stays crisp with nothing to
protect. Where tone must be dithered over such artwork, protect it:
`protectRects` maps items to rects on the grid, `protectMask` turns rects
into the mask `ditherPixels` takes, and `protectTexture` uploads that mask for
`dither`. Inside it pixels quantize at plain threshold, and error diffusion
neither enters nor leaves it.
````
