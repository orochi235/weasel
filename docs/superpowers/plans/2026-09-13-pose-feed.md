# Pose feed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `createPoseFeed(scene)` in core — a change channel that tells a renderer weasel does not own which nodes were added, removed or moved since its last read — and migrate the 3D lab onto it as the first host.

**Architecture:** The feed subscribes to the scene's two independent clocks. Committed edits bump `Scene.getVersion()`; ephemeral drag previews live in `Scene.overrides`, which has its own `getGeneration()` and names the ids it touches. Reading overrides costs `O(changed)`, so a drag never walks the node map; the `O(n)` walk runs only on frames where committed content changed. That walk compares the references a node *carries* — effective pose, data, layer — because the scene mutates node objects in place and swaps those references, leaving the node object `===` its own future self.

**Tech Stack:** TypeScript, vitest (`--project=core`), no new dependencies. Spec: `docs/superpowers/specs/2026-09-13-pose-feed-design.md`.

```ts
import { effectivePose } from './effectivePose';
import type { Node, NodeId, Scene } from './types';

/** A node and the pose a renderer should draw it at. `node.pose` beside it is
 *  still the committed pose, so a host has both without a second channel. */
export interface FeedNode<TData, TLayer extends string, TPose> {
  node: Node<TData, TLayer, TPose>;
  pose: TPose;
}

export interface FeedDelta<TData, TLayer extends string, TPose> {
  added: readonly FeedNode<TData, TLayer, TPose>[];
  removed: readonly NodeId[];
  changed: readonly FeedNode<TData, TLayer, TPose>[];
  /** Discard the object map and rebuild. */
  reset: boolean;
}

export interface PoseFeed<TData, TLayer extends string, TPose> {
  subscribe(fn: () => void): () => void;
  read(): FeedDelta<TData, TLayer, TPose>;
}

const EMPTY = Object.freeze([]) as readonly never[];

export function createPoseFeed<TData, TLayer extends string, TPose>(
  scene: Scene<TData, TLayer, TPose>,
): PoseFeed<TData, TLayer, TPose> {
  let seen: Map<NodeId, Node<TData, TLayer, TPose>> | null = null;

  const posed = (node: Node<TData, TLayer, TPose>): FeedNode<TData, TLayer, TPose> => ({
    node,
    pose: effectivePose(scene, node),
  });

  return {
    subscribe() {
      return () => {};
    },
    read() {
      if (seen === null) {
        seen = new Map(scene.nodes);
        return {
          added: [...seen.values()].map(posed),
          removed: EMPTY,
          changed: EMPTY,
          reset: true,
        };
      }
      return { added: EMPTY, removed: EMPTY, changed: EMPTY, reset: false };
    },
  };
}
```

### Task 2: Committed changes — the O(n) reference walk

**Read this before you start.** The scene **mutates node objects in place** and replaces `pose` and `data` with new references — `kit:setPose` in `packages/core/src/core/scene/scene.ts` is `(requireNode(p.id) as { pose: TPose }).pose = p.to` on the object already in `state.nodes`. Two consequences: caching the node object detects nothing, and a cached node's `.pose` has already moved. Snapshot `{ pose, data, layer }` per id instead — the same key `nodeMemo` uses, for the same reason. The snapshot's `pose` is the **effective** pose, so a derived node whose dependency moved is caught by the same comparison.

- [ ] **Step 3: Implement the walk**

Change `seen` to hold a reference snapshot rather than the node, track the version, and add a `walk()` beside `posed()`:

```ts
/** The three references a node carries that a renderer cares about. The node
 *  object is mutated in place, so it is these — not the node — that move. */
interface Snapshot<TData, TLayer extends string, TPose> {
  pose: TPose;
  data: TData;
  layer: TLayer;
}
```

```ts
  let seen: Map<NodeId, Snapshot<TData, TLayer, TPose>> | null = null;
  let seenVersion = -1;

  const walk = (): {
    added: FeedNode<TData, TLayer, TPose>[];
    removed: NodeId[];
    changed: FeedNode<TData, TLayer, TPose>[];
  } => {
    const prev = seen!;
    const added: FeedNode<TData, TLayer, TPose>[] = [];
    const changed: FeedNode<TData, TLayer, TPose>[] = [];
    const removed: NodeId[] = [];
    const next = new Map<NodeId, Snapshot<TData, TLayer, TPose>>();

    for (const [id, node] of scene.nodes) {
      const pose = effectivePose(scene, node);
      next.set(id, { pose, data: node.data, layer: node.layer });
      const before = prev.get(id);
      if (before === undefined) added.push({ node, pose });
      else if (before.pose !== pose || before.data !== node.data || before.layer !== node.layer) {
        changed.push({ node, pose });
      }
    }
    for (const id of prev.keys()) if (!next.has(id)) removed.push(id);

    seen = next;
    return { added, removed, changed };
  };
```

and in `read()`:

```ts
    read() {
      if (seen === null) {
        seen = new Map();
        seenVersion = scene.getVersion();
        // `seen` starts empty, so the walk reports every node as added and
        // fills the snapshot map in the same pass.
        return { ...walk(), removed: EMPTY, changed: EMPTY, reset: true };
      }

      const version = scene.getVersion();
      if (version === seenVersion) {
        return { added: EMPTY, removed: EMPTY, changed: EMPTY, reset: false };
      }
      seenVersion = version;
      return { ...walk(), reset: false };
    },
```

```ts
        seenOverridden = now;
```

```markdown
`Scene.overrides`, which names the ids it touched and costs `O(changed)`. A
`FeedNode` carries the effective pose beside the node's committed one, so a host
can draw both without a second channel.

The 3D lab is the first host.
```
