# Audit round 70 — ui.components.part8 (blind reviewer)

## ShortcutSheet's useSyncExternalStore has no server snapshot, so server rendering a page that mounts it throws
- where: packages/ui/src/components/ShortcutSheet/ShortcutSheet.tsx:78 (ShortcutSheet)
- scenario: an app server-renders (`renderToString` / streaming SSR) a shell that mounts `<ShortcutSheet open={false} …>`, as an app shell holding the sheet closed does. The hook runs whether or not the sheet is open, and React's server renderer throws "Missing getServerSnapshot, which is required for server-rendered content" because only two arguments are passed. The page errors (or falls back to client rendering at the nearest Suspense boundary) where it should render the closed sheet. Every other `useSyncExternalStore` in ui's components (ToolPalette.tsx:117, ContextMenuHost.tsx:19, MenuColorValue.tsx:23, fontOptions.ts:100, runSlots.ts:66) passes a third, server snapshot, so this is the one place the question is answered the other way. Passing the same getter (it returns `NO_ACTIONS` when closed) as the third argument fixes it.
- evidence: read (the call site, and the other components' calls for comparison); React's throw on a missing getServerSnapshot is from React's documented behavior, not run here
- severity: low
