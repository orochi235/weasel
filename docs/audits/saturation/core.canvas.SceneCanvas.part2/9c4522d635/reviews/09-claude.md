## `useViewportWithoutView` warns that navigation is dead when `viewport` only switches navigation off
- where: packages/core/src/canvas/SceneCanvas/useViewportWithoutView.ts:10 (useViewportWithoutView)
- scenario: a canvas without `corePresets.view` passes `viewport={{ pan: false }}`, `{ edgePan: false }` or `{ animatedZoom: false }`. Each of those values is `!== undefined`, so `unread` is true and a dev build warns "`viewport` configures the view preset … wheel, pinch, and the zoom keys do nothing". The caller asked for nothing to be turned on, so no navigation is being silently dropped and there is nothing to warn about. Only a key that asks for navigation (a value other than `false`) should count. The message also leaves out edge pan, which `SceneCanvasInput.tsx:169` gates on `viewOn` too.
