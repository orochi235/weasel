# Benchmark baseline

Generated by `npm run bench:baseline`. **These are one machine's numbers, not a threshold.** They are portable as ratios and curve shapes, not as absolute milliseconds. See `tests/bench/README.md`.

| | |
|---|---|
| Measured | 2026-08-14 |
| CPU | Apple M2 Max (12 threads) |
| Arch | darwin/arm64 |
| Node | v26.1.0 |
| Memory | 64 GB |

`median` is the number to compare — the mutating and allocation-heavy benchmarks take periodic GC pauses that inflate the mean by an order of magnitude without the code having changed. `rme` is the relative margin of error on the mean; a large one means read the median and ignore the mean entirely.
