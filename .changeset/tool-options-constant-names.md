rig's weight brush options constant is `WEIGHT_TOOL_OPTIONS`, named for the `weight` tool and ending in `_TOOL_OPTIONS` as core's `RECT_TOOL_OPTIONS` does.

```ts
// before
import { WEIGHT_BRUSH_OPTIONS } from '@weasel-js/rig';
// after
import { WEIGHT_TOOL_OPTIONS } from '@weasel-js/rig';
```
