rig's `WEIGHT_BRUSH_OPTIONS` is `WEIGHT_TOOL_OPTIONS`, named for the `weight` tool as core's `RECT_TOOL_OPTIONS` is named.

```ts
// before
import { WEIGHT_BRUSH_OPTIONS } from '@weasel-js/rig';
// after
import { WEIGHT_TOOL_OPTIONS } from '@weasel-js/rig';
```
