The path commands gain icons: `JoinIcon` on `joinPaths` and `joinAnchors`, `CutAtCrossingsIcon` on `snipAtCrossings`, `SimplifyIcon` on `simplifyPath`, `OffsetPathIcon` on `offsetPath`, and `AverageAnchorsIcon` on `averageAnchors`. `BridgeIcon` moves beside them in the path-command icon module and is still exported from `@weasel-js/core` under the same name. `livePathEdit`'s spec takes an optional `icon`.
