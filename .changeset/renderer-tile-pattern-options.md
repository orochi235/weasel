`TilePatternOpts` is renamed `TilePatternOptions`, the suffix every other options type uses.

```ts
// before
import type { TilePatternOpts } from '@weasel-js/renderer';
// after
import type { TilePatternOptions } from '@weasel-js/renderer';
```
