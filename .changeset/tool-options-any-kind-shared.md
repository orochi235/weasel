Tool options hold any prefs leaf, not only numbers, and an option can name a shared key (`ToolOptions.share`), so every tool naming it reads and writes one value; `shareToolOptions` lays a use site's share over a tool's own, `null` keeping an option per tool. Every read and write resolves its slot through `toolOptionSlot`, with `setToolOption`, `keepToolOptions`, and `heldToolOptions` beside `toolOptionParams`. `ToolOptions.actionId` may name several actions. `toolOptionsPrefs` builds the prefs group a host keeps options in, a group per tool and one `shared` group with host-given defaults, and `prefsToolOptionValues` reads and writes them in a prefs store. `withToolOptionDefault` changes one option's default. A tuning marked `under` lies beneath every other tuning of its action. The size and strength step actions moved to `toolOptionSteps.ts` and are exported as before. Breaking: `ToolOptionValues.get` returns `Record<string, unknown>`, and `set` takes any value and an owner, a tool's id or `SHARED_TOOL_OPTIONS`.
