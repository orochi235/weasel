The CSS Vars panel saves a token the theme derives, one that follows another token, a ramp, a contrast rule, or an alpha, as a pin over that token alone, in only the axis values the trial reads that its value varies on. The derivation keeps giving every other token, and this one everywhere else. A scale step edited by hand after its scale saves the same way, on top of the scale edit, which now saves too.
