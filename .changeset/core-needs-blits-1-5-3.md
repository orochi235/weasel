`@weasel-js/core` needs `@msb235/blits` 1.5.3 or later.

Its named easings and rewinds resolve through blits' `curve()` and the Penner curves blits 1.5.3 publishes. An app that pins an older blits raises it:

```sh
npm install @msb235/blits@^1.5.3
```
