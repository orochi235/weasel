A schema's path and value types are exported from `@weasel-js/prefs-schema`, so code declaring a schema needs no store.

That is `PrefPath`, `PrefAtPath`, `PrefValueAt`, `PrefValueOf` and `PrefFieldsOf`; `@weasel-js/prefs` still exports them too.
