New package, `@weasel-js/pdf`: `writePdf` turns draw commands into a PDF document — vector paths, gradient shadings, images, and fonts embedded whole so text can be selected and copied. `@weasel-js/font` adds `fontEmbedding`; `@weasel-js/diagram-formats` adds `exportPagesPdf`, every page of a diagram as one PDF.
