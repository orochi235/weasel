- where: packages/core/src/canvas/SceneCanvas/presetMerge.ts:47 (mergeByKey)
- scenario: presets A (`refines: ['B']`) and B (`refines: ['A']`) both on a canvas, each giving the same layer slot / chrome rule / tool id a different value. `resolveFeatures` accepts the cycle (`place` guards recursion and records both directions in `direct`), so `refines(A,B)` and `refines(B,A)` are both true. It should either reject the cycle with the `[SceneCanvas]` error naming both presets, or settle on one.
