# @weasel-js/headless

## 2.0.0

### Major Changes

- 040527c: Scenes with registered clips, derivations, compositions or quantize rules render from Node, given to the page with `serveHeadlessPage`.
  
  `@weasel-js/headless/page` no longer starts serving when imported. A custom page script registers what it needs, then calls `serveHeadlessPage` once; `scene` takes `loadScene`'s options and must match the scenes the host sends:
  
  ```ts
  // before
  registerFont(font);
  import '@weasel-js/headless/page';
  
  // after
  import { serveHeadlessPage } from '@weasel-js/headless/page';
  registerFont(font);
  serveHeadlessPage({ scene: { registry, composition, quantize } });
  ```
  
  A scene naming a registry key the page was not given is refused with an error naming the key and `serveHeadlessPage`. The default page script calls it with no options.
  
  <!-- entry: rank=10 breaking api new -->

### Minor Changes

- 4bdb39b: A raster host's render takes `renderSceneToPixels`'s `camera`, `layers` and `pixelRatio`, and refuses one of the wrong type before a browser starts.
  
  <!-- entry: api fix -->
- 949556e: The raster host refuses a render past `MAX_RESULT_BYTES`, about 10 000 × 10 000 RGBA pixels, naming the limit.
  
  An RGBA render is refused before a browser starts; a PNG once the page has encoded it.
  
  <!-- entry: fix api -->

### Patch Changes

- e542919: `@weasel-js/headless`'s types resolve on a clean install.
  
  It now depends on `@weasel-js/geom`, whose `Rect` its protocol types name.
  
  <!-- entry: fix -->
- caabd5f: A raster host's `dispose()` resolves only once every browser it launched is closed, including one it dropped after its page crashed or closed.
  
  <!-- entry: fix -->
- 179db38: The raster host sends a live `Scene`'s node data to the page as the scene holds it, even data shaped like the snapshot codec's tags.
  
  <!-- entry: fix -->
- 6d62b45: A raster host whose page fails to open rejects with the error that stopped it, even when its cleanup fails too.
  
  <!-- entry: fix -->
- d1ad203: `serveHeadlessPage({ scene })` takes options typed for `RectPose` scenes, and `@weasel-js/headless/page` exports their type, `PageSceneOptions`. A registry whose functions read `RectPose`s was refused by the type checker before, although the page draws only 2D scenes.
  
  <!-- entry: fix -->
- ec6720c: The raster host goes on rendering after its page's WebGL2 context is lost: the next render opens a new session.
  
  <!-- entry: fix -->
- 54cc860: A raster host rejects with the error its page script threw, rather than saying the script never called `serveHeadlessPage`.
  
  <!-- entry: fix -->
- 54cc860: A raster host's page script may call `serveHeadlessPage` after its fonts load, up to 30 seconds after it runs, rather than only at once.
  
  <!-- entry: fix -->
- ea1ce27: A raster host sends a raw scene snapshot holding typed arrays with its own data as it holds it, numbers under `coords` or `commands` included.
  
  <!-- entry: fix data -->
- 5f6ebf3: A render request carries its scene through core's snapshot codec, so a snapshot saved with untagged path arrays renders its paths.
  
  <!-- entry: behavior data -->
- faf8481: A raster host whose page crashed or closed between renders opens a new page for the next render instead of failing it.
  
  <!-- entry: fix -->
- ee83714: A raster host refuses by name any render whose result would not fit the protocol message that carries it to Node.
  
  `MAX_RESULT_BYTES` is 401 866 734, leaving 1 MiB for that message.
  
  <!-- entry: fix -->
- ff0a61f: A raster host opens a new page for the next render once its page lost a WebGL2 context and could not get another.
  
  <!-- entry: fix -->

- 99b8ada: Fixes to slews, color cycles, bus gains and the node raster host found by an audit of the motion and media packages.
  
  - `slewToward` and `createSlew` stay finite over a step of zero time. A direction with no rate jumps to the target whatever the step, and a limited one holds over a zero, negative or NaN step. Before, an unlimited direction over `dt` 0 answered NaN, and a slew kept that NaN from then on.
  - `cycleVertexColors` throws a `RangeError` for a `msPerCycle` that is not positive, before it installs anything. Before, 0 or NaN painted NaN colors, and a negative time turned the colors backward, which `direction: -1` does.

  - A node raster host's `render` returns pixels whose `data.buffer` holds only them. Before, a small image was a view into Node's shared `Buffer` pool.
  - A node raster host disposed while its page is still opening rejects the render in flight as on a disposed host, rather than with the closed page's error.
- db5276d: Fixes to audio voices and patterns, clock syncing, timeline seeks, tween durations and the node raster host.
  
  - A voice's `gain`, `rate`, `detune`, `pan` and `position`, given to `play`, `playNote`, `playNoise` or `stream` or set on its handle, and the position `setListener` takes, throw a `RangeError` when not finite.   - `animator.tween` throws a `RangeError` on an `ms` that is NaN, for a plain tween and a target tween alike. Before, the tween started and its first frame threw out of the animator's frame, stopping every other animation on every frame after.

- 13b0604: Breaking: `@weasel-js/headless` now holds what was announced as `@weasel-js/node-render`, which never published under that name. Its 1.15.0 contents (list, focus, slider, reorder and tree keys, and the measure/draw contract) moved to `@weasel-js/ui-logic` unchanged; import them from there.
  
  What the package does now: render a scene to pixels from Node. `createNodeRasterHost()` runs core's `renderSceneToPixels` in a headless Chromium page launched through `playwright-core` on the first render, and keeps that page, its WebGL2 context and its GPU caches across renders until `dispose()`. `render` returns the raw straight-RGBA raster and `renderPng` a PNG; the scene goes in live or as its `toJSON()` snapshot, with its paths' typed arrays tagged on the way. `@weasel-js/headless/page` is the page's script, for a consumer bundling its own page to register fonts or painters first. The browser itself is not bundled: install it with `npx playwright install chromium`.
