# @weasel-js/ui-canvas

## 2.0.0

### Major Changes

- 59c8842: `CharacterOptions` takes the styling it shows as `value` and reports each edit through `onChange`, where they were `style` and `onPatch`.
  
  ```tsx
  // before
  <CharacterOptions style={edit.effectiveStyle} onPatch={edit.applyStyleToSelection} />
  // after
  <CharacterOptions value={edit.effectiveStyle} onChange={edit.applyStyleToSelection} />
  ```
  
  <!-- entry: breaking api -->
- 0765242: `SelectionPanel` takes `marked` and `onMark`, where it took `selected` and `onSelect`.
  
  They are the rows it marks and a press on a row; `selection` stays the scene's selection it edits.
  
  ```tsx
  // before
  <SelectionPanel scene={scene} selection={selection} selected={rows} onSelect={pick} />
  // after
  <SelectionPanel scene={scene} selection={selection} marked={rows} onMark={pick} />
  ```
  
  <!-- entry: breaking api -->

### Minor Changes

- 800e293: `kitIcons` moves from `@weasel-js/ui/kit-icons` to `@weasel-js/ui-canvas/kit-icons`.
  
  This is breaking: import it from `@weasel-js/ui-canvas/kit-icons`. It lists core's, editing's, the shapes', the paint kinds' and ui's tables, which ui alone cannot name. `@weasel-js/ui/icons` still has ui's own.
  
  <!-- entry: breaking api -->
- 800e293: Scene panel helpers move from `@weasel-js/ui` to `@weasel-js/ui-canvas`, and `classifyKind` is gone.
  
  The helpers are `useSceneLayerList`, `SceneGradientHandles`, `aggregateValue` (renamed `sharedNodeValue`) and `nodeValueAt`.
  
  This is breaking: import `useSceneLayerList`, `ANNOTATION_LAYER_ROW` and their types from `@weasel-js/ui-canvas/components/SceneLayerList`; `SceneGradientHandles`, `SceneGradientHandlesProps` and `PaintedNodeData` from `@weasel-js/ui-canvas/components/SceneGradientHandles`; and `sharedNodeValue`, `nodeValueAt` and `AnyNode` from `@weasel-js/ui-canvas`. In place of `classifyKind(node, routing)`, call core's `routeKind(routing, node.data, node)`, which it wrapped. ui's `LayerList` and `GradientHandles` stay in `@weasel-js/ui`.
  
  <!-- entry: breaking api -->
- 800e293: New package `@weasel-js/ui-canvas`: the ui components bound to a weasel canvas, from `SelectionPanel` to `Rulers`, and `kitIcons`.
  
  It holds `SelectionPanel`, `AnchorFields`, `CharacterOptions`, `useSceneLayerList`, `SceneGradientHandles`, `Rulers`, `PlotDataPanel` and `kitIcons`, at the same `./components/*` and `./kit-icons` subpaths they had in `@weasel-js/ui`, with a stylesheet of its own at `@weasel-js/ui-canvas/style.css`. It depends on `@weasel-js/ui` and takes `@weasel-js/core` and `@weasel-js/editing` as peers.
  
  <!-- entry: rank=10 new api -->
- 800e293: `SelectionPanel`, `AnchorFields`, `CharacterOptions`, `Rulers` and `PlotDataPanel` move from `@weasel-js/ui` to `@weasel-js/ui-canvas`.
  
  This is breaking: import them, with their props types, `CHARACTER_OPTIONS`, `isCharacterChrome`, `HandleCoords` and `PlotTableView`, from `@weasel-js/ui-canvas`, or from `@weasel-js/ui-canvas/components/inspector/SelectionPanel` and the other subpaths `@weasel-js/ui` had for them. Load `@weasel-js/ui-canvas/style.css` beside ui's.
  
  ```ts
  import { SelectionPanel } from '@weasel-js/ui-canvas/components/inspector/SelectionPanel';
  ```
  
  <!-- entry: rank=20 breaking api -->

### Patch Changes

- 53e4428: `CharacterOptions` shows a solid text fill's opacity in its color swatch and keeps it when the color is changed.
  
  <!-- entry: fix -->
- 471581b: Packages no longer install weasel siblings their code never uses.
  
  `@weasel-js/editor` stops asking for `@weasel-js/geom` as a peer and takes `@weasel-js/editing` only as one; `@weasel-js/prefs-editor` drops `@weasel-js/paint-kinds`, `@weasel-js/ui` drops `@weasel-js/storage`, `@weasel-js/icons-plugin` drops `@weasel-js/icons`, `@weasel-js/labkit` drops `@weasel-js/animator`, `@weasel-js/measure` drops `@weasel-js/theme`, `@weasel-js/rig` drops `@weasel-js/history` and `@weasel-js/renderer`, `@weasel-js/text-tools` drops `@weasel-js/icons` and `@weasel-js/prefs-schema`, and `@weasel-js/ui-canvas` drops `@weasel-js/history`.
  
  <!-- entry: internal -->
- 5ffb146: `SceneGradientHandles` writes a dragged gradient to `nodeId` alone, rather than to every selected node.
  
  <!-- entry: fix -->
- ceb50a6: `useSceneLayerList` adds a Cmd-clicked content row to the selection while an annotation is picked.
  
  The annotation is unpicked when its row is deselected or another row is clicked.
  
  <!-- entry: fix -->
- b8cb393: `PlotDataPanel` clears a failed edit's message when a different chart is passed in.
  
  An error its `onChange` throws now propagates rather than showing as the edit's.
  
  <!-- entry: fix -->
- c6300b8: A `SelectionPanel` edit canceled over a mixed selection puts each node back to its own value.
  
  <!-- entry: fix -->
- f0ac203: `SelectionPanel` warns in development about a schema field it draws but can never save.
  
  That is a field keyed outside `pose.`, `data.` or a declared field such as `clip`; it warns once per kind and path.
  
  <!-- entry: fix -->
- 471581b: `@weasel-js/ui-canvas`'s types resolve on a clean install.
  
  It now depends on `@weasel-js/geom`, `@weasel-js/history` and `@weasel-js/quantity`, and takes `@weasel-js/guides` as a peer: `Rulers` reads a rulers model made by `@weasel-js/guides`, so an app showing rulers installs that package itself.
  
  <!-- entry: fix -->
- 76aeab9: A top-level drag in a scene's layer list lands where it was dropped when the page run shares that level with pasteboard roots.
  
  <!-- entry: fix -->
- 8f300d8: PlotDataPanel keeps an opened row open on its item when a row is added, removed or dragged above it.
  
  <!-- entry: fix -->
- 7e7f2d4: SelectionPanel settles writes through the same properties entry it draws: the last one of a kind's name.
