# @weasel-js/gestures

Pure gesture taxonomy, route grammars, and matcher primitives. No React, no DOM, no scene.

Part of [weasel](https://github.com/orochi235/weasel), a domain-agnostic 2D
scene-graph canvas kit for React. See the
[API reference](https://orochi235.github.io/weasel/api/).

## Install

```sh
npm install @weasel-js/gestures
```

## Usage

```ts
import { /* … */ } from '@weasel-js/gestures';
```
