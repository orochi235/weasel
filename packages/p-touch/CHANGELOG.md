# @weasel-js/p-touch

## 2.0.0

### Major Changes

- 192023f: dither's option types are named for the function they configure.
  
  `ditherPixels` takes `DitherPixelsOptions` (formerly `DitherOptions`), and `dither` takes `DitherOptions` (formerly `GpuDitherOptions`).
  
  ```ts
  // before
  const cpu: DitherOptions = { method: 'atkinson' };
  const gpu: GpuDitherOptions = { method: 'bayer' };
  // after
  const cpu: DitherPixelsOptions = { method: 'atkinson' };
  const gpu: DitherOptions = { method: 'bayer' };
  ```
  
  <!-- entry: breaking api -->
- d20e552: `lbxObjects` is `lbxObjectsCommand`, since it returns a draw command carrying the objects, not the objects.
  
  ```ts
  // before
  drawOne: (node) => [lbxObjects([barcode])]
  // after
  drawOne: (node) => [lbxObjectsCommand([barcode])]
  ```
  
  <!-- entry: breaking api -->

### Patch Changes

- 205de56: `writeLbx` and `sceneToLbx` throw a `RangeError` for an auto-length label longer than 1000mm. That is the longest P-touch sizes one to (`AUTO_LENGTH_MAX_PT`).
  
  <!-- entry: fix behavior -->
- c27cb27: `writeLbx` rasterizes a wrapping justified text box aligned center or right. P-touch would set its last line at the left; a box that never wraps is written with its `align`.
  
  <!-- entry: fix visual -->
- 9e55cb7: `writeLbx` rasterizes a polyline whose stroke, caps, or mitered corners reach past the label's ends, as it does a rect. P-touch no longer grows an auto-length label for a line's cap.
  
  <!-- entry: fix -->
- ade9e8d: `writeLbx` without a rasterizer reports a skipped group by its own kind, not by the kind of the one command inside it.
  
  <!-- entry: fix -->
- 9c8724c: Under `autoLength`, a shape or text box reaching past an end of the label is drawn into the `.lbx` as an image cropped to the label.
  
  It no longer stretches the printed label past the length it was given, and is cut where rasterized paint beside it is.
  
  <!-- entry: fix data -->
- 5ea15b7: `lbxObjectsCommand` objects under a transform that scales an axis to zero are left out of the `.lbx` with no skip report.
  
  The canvas draws nothing there.
  
  <!-- entry: fix data -->
- 5ea15b7: `lbxObjectsCommand` objects inside a rect clip drawn under a mirror are written to the `.lbx`, rather than skipped as cut by the clip.
  
  <!-- entry: fix data -->
- fc28caf: A polyline whose corners are rounded, beveled, or past its miter limit is drawn into the `.lbx` as an image, since P-touch would miter them.
  
  <!-- entry: fix data -->
- c65efd6: A rect whose stroke miter limit makes the canvas bevel its corners is drawn into the `.lbx` as an image.
  
  That is a miter limit below √2; such a rect was written with square corners.
  
  <!-- entry: fix data -->
- 87f1310: `renderLabel` draws on white when its `background` is passed as `undefined`, as it does when the field is left out.
  
  <!-- entry: fix visual -->
- 6d5df61: A square-capped line is drawn into the `.lbx` as an image, so its ends keep the half stroke width they reach past its points.
  
  <!-- entry: fix data -->
- 74d1f11: A text box that does not wrap on the canvas is written to the `.lbx` with auto line feed off, so P-touch keeps each of its lines whole.
  
  <!-- entry: fix data -->
- ac434c3: Text drawn with OpenType features, such as small caps from the face's own glyphs, goes into the `.lbx` as an image.
  
  <!-- entry: fix data -->
- 9d6f1d2: A text box with its own `lineHeight` or `tabSize` is drawn into the `.lbx` as an image when it would use them.
  
  That is a box of more than one line for `lineHeight`, and one holding a tab for `tabSize`, so its lines and tab stops sit where the canvas puts them.
  
  <!-- entry: fix data -->
- 414b107: A text box the canvas lays out right to left is drawn into the `.lbx` as an image, so `start` and `end` stay on its side.
  
  That covers a style `direction` of `rtl` and an `auto` paragraph whose first strong letter reads right to left.
  
  <!-- entry: fix data -->
- 954b5a4: A text box that wraps at a width other than the one it aligns in is drawn into the `.lbx` as an image.
  
  <!-- entry: fix data -->
- aaa6a30: `sceneToLbx` rasterizes at the `pixelRatio`, `screen`, and `flattenTolerancePx` it is given. Screen-unit paint, `{ px }` lengths, and curves match `renderLabel` with the same arguments.
  
  <!-- entry: fix visual -->
- d95f5b3: `tapeForWidthMm(4)` finds the 3.5mm tape, which a printer's status reply reports as 4mm.

## 1.18.2

### Patch Changes

- fc38c90: Fixes to pattern tiles, text bounds, markdown layout and pasted tables, and the image cache closes the bitmaps it drops.
  
  - A `chunks` tile whose `chunkSize` is zero, negative or NaN, or whose `density` is infinite, scatters no chunks. Before, a zero size looped forever building the tile and hung the page, and a negative one threw from the canvas. A `dots` tile with a negative or NaN `radius` draws no dot rather than throwing.
  - A text command's painted bounds reach each glyph's pen step as well as its advance, so a retained group no longer cuts off the end of an underline, strikethrough or overline that letter spacing carries past the last letter.
  - `layoutMarkdown` measures its width without spreading every line into one call, which overflowed the stack on a text of a million lines or so.
  - A pasted table row keeps a tab for each empty cell before a cell with text, so `a`, an empty cell and `b` paste as `a\t\tb` rather than `a\tb`.
  - The image cache owns its bitmaps and closes each one it drops: evicted to fit its budget, released with `releaseImage`, replaced by a sharper SVG raster, or landing for a load already released. Before, it dropped them without closing them, leaving their memory until garbage collection. **A bitmap taken from the cache with `getImageBitmap` is valid only until the cache drops it**, so read it again each frame rather than keep it. A draw command still holding a closed bitmap draws nothing. Work that holds draw commands across an `await` can call the new `holdImageBitmaps()` (from `@weasel-js/renderer` and `@weasel-js/core`), which keeps what the cache drops open until the hold is released; `writePdf`, `exportPagesPdf` and `sceneToLbx` hold one themselves. A `bitmapSrc` bitmap is still its maker's and is never closed.

- b93c1dd: Fixes from an audit of ui-logic, editor and the icon packages, and one definition each for decisions several packages answered separately:
  
  - The icons plugin reads the namespace of an `icons.gen` compiled to JavaScript, so its `icon()` calls are rewritten as a TypeScript one's are.

  - New in geom: `rectBetween(ax, ay, bx, by)`, the rect two corners span, used by core's drag rect, marquee, area select, anchor marquee, insert extent, measurement and parallax, and by diagram's segment boxes.
  - New in registry: `freshId(base, taken, opts)`, the first free numbered id, used by core's `nextPageId`, diagram's stage, wire, group and sequence ids, and labkit's snapshot names.
  - paint exports `byteHex` and `lerpHueDeg`. core's `withAlpha01` and p-touch's lbx colors write hex through the first. theme's ramps blend hues through the second, so two anchors exactly opposite now blend the positive way round, as CSS's `shorter` does, where before they went the negative way.

  - A `compact` value that shows as `1.00K` (999.6, say) is now spoken `1 thousand`, not `1.00K`.
  - `nearestFraction` reads a denominator cap under 1 as 1 instead of returning a fraction over 0.
  - `parseColor` throws on an empty or non-decimal channel: `rgb(255, 0, 0,)` used to parse as transparent red, `rgb(1 2 3 / foo)` as opaque, and `rgb(0x10, 0, 0)` as hex.
  - `paintKey` gives two solids one key when their colors are the same color spelled differently (`#fff`, `#FFFFFF`, `white`).
  - `sampleGradientStops` reads a NaN position as the first stop instead of writing `#NaNNaNNaNNaN`, and answers an empty stop list in hex (`#00000000`) like every other answer.
  - `hexToColorLiteral` leaves `alpha` off a fully opaque `#rrggbbaa`, as `cssColorLiteral` does.
  - `writeLbx` frames a rect drawn with a negative width or height where it lies, and writes a cut position given twice only once.
