## 1.14.2

### Patch Changes

- 4b15345: `elkPlan` and `elkPlanner` now place nodes by network simplex rather than ELK's default, Brandes–Köpf, which
  could run a long edge's chain past the drawing's outermost node: on a 28-node grouped graph, 7 wires ran
  outside every node and group box, by up to 197 units. Network simplex keeps them inside and drew that graph
  19% narrower, at the cost of more bends (206 against 140), since it no longer lines every edge's ends up.
  This changes where nodes land; pass `layoutOptions: { 'elk.layered.nodePlacement.strategy': 'BRANDES_KOEPF' }`
  for the old placement.
- 5677062: `elkPlan` names the port on the face of the node ELK's route meets, nearest first, rather than the
  nearest port overall, which on a wide box could sit on another face and draw the wire across the box.

## 1.11.0

### Patch Changes

- c08907e: New package, `@weasel-js/diagram-elk`: lays a diagram's `Graph` out once with ELK (elkjs) and answers with the diagram's own `LayoutPlan` — moves, routes, label places and the port each edge end meets — plus each group's box as ELK sized it and the pins it could not hold. Ports an edge names, edge labels and nested groups all go to ELK. elkjs's bundled build (about 1.6 MB, 467 KB gzipped) loads on the first layout, or a worker-backed ELK can be passed in.
  
  `@weasel-js/diagram/layout` now also exports `anchorOffset`, `GraphGroup` and `LayoutPorts`, and the main entry `anchorOffset`.
- 4f7c861: A live layout and `DiagramView`'s `layout()` take a `LayoutPlanner`: an object whose `plan(graph, opts)` answers with a whole `LayoutPlan`, now or as a promise. The run asks it once, with the graph as it stands, and eases to the answer as it eases to `layered`'s, with the same route easing and the same moves, routes and ports reported to `onMove`. While the answer is pending, a newer request, `cancel`, `stop`, or a graph that moved or changed drops it, and `isRunning()` is true. A change of shape mid-run asks the planner again. A planner that rejects starts no run and reports the reason to the new `onError` option (`DiagramView`'s `live.onError`), or to `console.error` when that is unset; it is never left an unhandled rejection. `plannerPlan` lays a planner's graph out by footprint the way `planOf` does, and `DiagramLayout` names what `layout()` takes. `DiagramView` now fits again once a layout run settles, while the view is still its fit. `@weasel-js/diagram-elk` adds `elkPlanner(opts)`, ELK as a `LayoutPlanner`. Additive.
